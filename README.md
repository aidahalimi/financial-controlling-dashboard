# Financial Controlling Dashboard

## 📊 Project Overview

This project focuses on analyzing the financial performance of a fictional international company.

The dashboard provides insights into revenue, costs, profitability and budget performance.

## 🎯 Business Questions

- How is revenue developing over time?
- Which business units are most profitable?
- Where are the largest budget deviations?
- Which cost centers require attention?
